# KU Leuven-to-synthetic transfer stress test

## Purpose and interpretation

This experiment tests whether the early-engagement model trained on the
authorised KU Leuven release can be applied unchanged to the synthetic
Indian-university planner rows. It is deliberately a transfer stress test: the
source model is not refitted on synthetic data, and the result is not claimed
as validation of synthetic realism, Indian-university generalisation, or
production readiness.

The experiment is necessary because a synthetic model can achieve strong
within-generator scores while still using relationships that do not transfer
to independently collected observations. A failed transfer result is therefore
useful evidence of measurement and distribution shift, not evidence that the
synthetic generator is wrong by itself.

## Comparable feature contract

The two datasets do not have identical schemas. To avoid silently treating
planner-specific synthetic variables as if they were observed LMS variables,
the transfer test uses only these six early-engagement predictors plus course
category:

| Feature | KU Leuven source | Synthetic source | Rationale |
|---|---|---|---|
| `course_id` | Course identifier | Course identifier | Controls for course-level differences |
| `activity_count` | LMS activity rows | Study-session rows | Observable engagement-event count |
| `active_day_count` | Distinct activity dates | Distinct planned session dates | Breadth of engagement over time |
| `content_count` | Distinct LMS content IDs | Distinct topic IDs | Content-exposure proxy |
| `session_count` | Distinct LMS session IDs | Distinct study-session IDs | Engagement grouping proxy |
| `mean_daily_activity` | Activity count / active days | Session count / active days | Intensity conditional on observed days |
| `has_activity` | Positive activity indicator | Positive session indicator | Explicit zero-activity signal |

Synthetic sleep, screen time, break time, wellbeing, CGPA, attendance,
recommendations, and planner-only fields are excluded. They have no directly
comparable KU Leuven measurement in this evaluation. Synthetic study sessions
are a proxy for LMS activity; they must not be described as the same observed
behaviour.

For each cutoff, synthetic sessions are included only when their planned start
falls between the academic-term start and the inclusive cutoff date. The
synthetic label is `target_risk = 1 - passed` and is used only for evaluation.

## Protocol

1. Train the four existing baseline candidates on KU Leuven 1819.
2. Select one model and one operating threshold using KU Leuven 1920
   validation PR-AUC and the documented tie-break rules.
3. Refit the selected source model on 1819+1920, without using 2021 or any
   synthetic row, and keep that fitted source model unchanged during transfer.
4. Build synthetic enrollment-level features independently at 30, 60, and 90
   days.
5. Apply the source model to all 12,000 synthetic enrollments.
6. Report ROC-AUC, PR-AUC, balanced accuracy, F1, Brier score, calibration
   error, and confusion matrices. The source validation threshold is reported
   separately from the default 0.5 diagnostic.

The source model selected at all three cutoffs was logistic regression. The
synthetic release contains 12,000 enrollment rows and 12,000 outcomes. Its
positive risk prevalence in this run is 152 / 12,000 = 1.27%; this severe class
imbalance is why accuracy alone is not an adequate transfer criterion.

## Measured results

Generated by:

```powershell
.\.venv\Scripts\python.exe -m pipeline.cross_dataset_transfer `
  --kuleuven-path data/raw/external/kuleuven/dataset.zip `
  --synthetic-path data/raw/synthetic `
  --metrics-output models/metrics/cross_dataset_transfer_metrics.json `
  --cutoffs-days 30 60 90
```

The source validation thresholds were 0.30, 0.20, and 0.30 for the 30-, 60-,
and 90-day models respectively. All 12,000 synthetic rows received a positive
risk prediction at both the default and source thresholds. The resulting
confusion matrix is therefore `[[0, 11848], [0, 152]]` at every cutoff.

| Cutoff | Source model | ROC-AUC | PR-AUC | Balanced accuracy | F1 | Brier | ECE |
|---:|---|---:|---:|---:|---:|---:|---:|
| 30 days | Logistic regression | 0.5067 | 0.0128 | 0.5000 | 0.0250 | 0.5968 | 0.7644 |
| 60 days | Logistic regression | 0.5133 | 0.0130 | 0.5000 | 0.0250 | 0.6660 | 0.8084 |
| 90 days | Logistic regression | 0.5133 | 0.0130 | 0.5000 | 0.0250 | 0.6915 | 0.8240 |

At the source validation threshold, the confusion matrix remains
`[[0, 11848], [0, 152]]` for all three cutoffs. Recall is 1.0000 only because
the model predicts every row as risk; precision is 0.0127, equal to the
synthetic risk prevalence. ROC-AUC is near 0.5, indicating no useful ranking
separation on this target. The high Brier scores and expected calibration error
show that the probabilities are not calibrated for the synthetic label.

## Formal conclusion

The KU Leuven model does not transfer usefully to the current synthetic
feature distribution. The dominant failure is not a small loss in accuracy;
it is a probability and threshold shift that causes an all-positive policy.
The result is consistent with the two datasets measuring engagement through
different processes and having very different label prevalence. It also shows
why a model trained on one dataset must not be deployed on the synthetic
planner without target-domain calibration and validation.

This experiment does not prove that the synthetic data is unrealistic in every
respect. It identifies a concrete unresolved risk: the shared engagement
contract is not distributionally aligned with the KU Leuven contract. Before
any real deployment, the project still requires consented institutional data,
prospective labels, target-domain calibration, subgroup analysis, and an
intervention study. Synthetic-only planner features remain development
features until such evidence exists.
